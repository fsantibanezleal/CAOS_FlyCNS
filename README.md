# flycns

Compile a fly connectome release into a graph a simulator can run, model the two compound eyes over the release's own
optic-lobe columns, and simulate the whole central nervous system with the published neuron models, in Python and in
the browser, with the two implementations held to each other by parity tests.

Status: design written (`docs/design/SDD.md`); implementation starts with the MaleCNS v1.0 compiler.
